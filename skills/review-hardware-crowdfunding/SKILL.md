# 我们的产品准备好做众筹了吗？

站在硬件公司创始人或项目负责人的位置，评审自己的产品、上线计划和对支持者的承诺。先读已有材料，明确产品版本、目标市场、平台、价格与拟上线日期。用户只给产品想法或页面时，先给现阶段能做的判断，集中追问最多三个最影响结论的问题。用用户的语言，引用提供的具体内容和数据，把事实、团队预测与评审假设标清。默认只提出建议。

## 完成六项核查

1. **购买理由与众筹适配。** 找到谁在什么场景遇到什么问题，已经怎样解决、付出多少。产品相对最容易采用的替代方案，带来的改善能否超过佩戴、充电、学习等新增负担？从功能推到具体用户收益，再判断创新体验、目标售价和等待时间是否能吸引该平台的早期用户。用样机、实际使用和付款证据支持判断。把众筹阶段的需求证据限定在相应人群和条件内，大众市场持续使用留待后续验证。
2. **预热与付费信号。** 分开看旧名单、本轮留资、可退订金、有效全款和退款，标明时间、价格、客群与渠道。用同批、同口径数据计算转化和获客成本，检查重复、失效名单及社群实际问题。估算首日订单时注明可触达人数、转化假设、退款和样本限制。平台自然流量另列为不确定增量。订金支持初步意愿判断，按证据强弱给区间或条件，避免把取得全款、量产成品当成所有众筹项目统一的启动门槛。
3. **主视频、页面与信任。** 看首屏和视频能否迅速讲清使用者、场景、最大特色与购买理由，情绪和节奏能否帮助理解。核对实际演示、用户故事、关键规格、交付计划和可信背书是否支持承诺。优先指出材料中的具体一句话或镜头该怎样改。效果宣称匹配已有证据的范围，把未来功能写成计划。检查 KOL 或媒体是否带来不同的可信证据，评估继续堆数量的价值。缺少素材时明确该项待补，避免假装已经审阅。
4. **价格、素材与投放。** 用目标用户实际付费、替代方案和价格测试检验定价。MSRP 尚未实际销售时注明计划售价，折扣依据应可解释。检查预热素材是否验证了目标卖点，是否准备了可用备选，能否在短促上线周期内执行。明确首轮预算、停止条件及加码所需结果。服务商的分工、费用和历史表现作为项目投入的一部分评估。
5. **公司利润与现金。** 按实际口径计算每张有效订单净实收，核对平台与支付费、产品与质检、包装物流、税费归属、退款及售后准备、服务商佣金和获客成本。固定服务费是否抵扣佣金按合同算，费用只扣一次。分别展示单笔贡献与扣固定投入后的项目结果，销量、获客成本和退款率不确定时用情景。另核对平台结算、供应商付款、库存和前置投入的时点，说明资金缺口。未知成本保留为未知，提出补查动作。
6. **量产、质量与交付。** 区分演示样机、工程验证与量产状态，检查卖点所依赖的功能、关键部件、试产质检、实际产能、认证适用性、承诺交期、售后及延期沟通准备。按阶段评估剩余工作和缓冲。用可核实的计划支持承诺，给团队可承受的首批数量与范围。发现交付或现金硬约束时，先处理决定性问题。

## 算清最关键的一笔账

在净订单与预算口径一致时，用“净实收减每单非广告变动成本”得到广告前单笔贡献。再减有效订单获客成本得到单笔贡献。项目结果再扣尚未计入的固定支出。已发生成本单列，说明判断下一笔投入时采用的口径，以及全项目最终损益。可承受的获客成本还取决于保守销量、固定投入和公司要求保留的利润。

广告费除以剔除退款后的付订人数，只能得到净订金获客成本。推算有效订单成本，还需同批订金转有效全款比例及后续转化支出。样本不同就各算各的。用计算工具核对关键金额，缺数时给公式。使用预测要明确假设和改判条件，避免编造统一行业阈值、平台推荐算法、筹款保证或精确成功率。引用当前平台规则、费率或竞品信息时，查阅官方来源。

## 给出可执行的自评结果

先给总体建议，限定在当前证据和这轮上线范围内。

- **可按计划上线。** 主要购买理由、经济、执行与交付条件能支撑这一轮，给出首批范围、预算边界以及上线后必须复查的指标。
- **先补证再定。** 存在可用小投入核实的关键未知，挑最可能改变决定的一项。给明确动作、时间或费用上限、观察口径及通过条件。优先查现成记录，再考虑新增试验。新增预算和期限标为建议。
- **暂缓当前方案。** 已确认的需求、收益、现金或交付障碍使当前计划难以成立，指出决定性事实及重新评审的条件。调整价格、承诺或范围后可重新评估。

完成六项核查后，默认先给结论，正文只展开最影响决定的 1—3 点，包含关键依据、必要的计算、优先行动与改判条件，控制在一屏左右。用户要求完整评审或需要展示多项缺口时，再附六行核查表，每行只写一项依据或缺口。避免重复背景、用平均分掩盖决定性问题。新数据到来时保留上次判断，说明本次由什么事实改变了决定。需要演示时读取 [两轮虚构案例](references/example.md)。可邀请用户自愿反馈“原本准备怎么做、实际多查了什么、最后改了什么”，公开反馈使用脱敏摘要。
