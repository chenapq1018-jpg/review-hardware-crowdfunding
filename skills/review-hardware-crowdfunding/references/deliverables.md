# 交付规格与示例

每轮根据最大瓶颈完成一份可直接派工的成果，结论说明为什么先做它。
接收现有链接、页面、视频或脚本、用户记录、广告导出和报价，先提取资料，缺项集中追问。
下列产品、人物、记录与金额全部虚构。数字为示例假设，实际使用时替换为项目材料并复算。
文案与实验是供团队采用的草稿，所有对外效果承诺要有对应证据。

## 路由

| 当前瓶颈 | 完成的成果 | 默认执行角色 |
| --- | --- | --- |
| 使用价值与目标用户不清 | 一页产品定义修订 | 产品负责人 |
| 主张清楚但页面或视频表达失效 | 首屏改稿与一段分镜 | 品牌负责人、设计、视频制作 |
| 愿意买的证据不足或口径混乱 | 一张付费验证实验卡 | 增长负责人、数据分析 |
| 获客、固定投入和回款无法支撑计划 | 可复算预算与付款调整方案 | 财务、增长、供应链 |
| 核心功能、质量或交期承诺超出进度 | 首批范围与交付承诺修订 | 硬件负责人、供应链、客服 |

五条路由共用现有事实。只展开决定本轮行动的计算和修订，其他缺口列为依赖项。
交付物标明适用版本、源材料位置、角色负责人、建议完成时点、验收证据与改判条件。
用户没有提供原文、镜头或记录时，交付相应假设稿，并标明需要补入的位置。

## A. 产品定义修订

### 最小输入与交付

读取用户、使用场景、现有替代方案、功能状态和实际体验记录。
完成一个推荐定义，把购买理由、功能边界、使用负担、证明方式和验证动作连起来。
每项修改引用材料中的具体冲突，例如“原定义称教练，现有测试只记录回球成功”。

### 完整示例片段

本例假设团队开发室内固定点位回球器，只有工程样机，已能原速演示回球。
目标售价暂定 429 美元，十名目标用户试用中有八人提到少走动捡球，尚无该售价付款记录。
这些试用反馈仅用于提出购买理由假设，价格接受度留待验证。

| 产品定义项 | 本轮修订 |
| --- | --- |
| 目标使用者 | 经常独自做固定点位投篮练习、愿意布置设备的业余球员 |
| 具体任务 | 在一次有限练习时间里连续完成自己安排的投篮练习 |
| 现有做法 | 投篮后走去捡球，或使用已有的简单回球装置 |
| 推荐购买理由 | 让单人投篮练习少被捡球打断 |
| 本轮功能范围 | 工程样机已经演示的室内固定点位回球，按测试条件描述摆位 |
| 新增负担 | 搬运、摆位、校准和收纳时间待实际计时，公开所需场地 |
| 差异证明 | 同一场地比较最容易采用的回球方式，记录准备与练习中的中断 |
| 下一步动作 | 产品负责人复核完整使用记录，增长负责人用明示价格验证购买行为 |

交给产品负责人的验收件是一份带准备过程的完整使用记录和更新后的范围说明。
若最简单替代方案已能以更小负担取得相似体验，应调整价值主张或产品定义再测。

## B. 首屏改稿与视频分镜

### 最小输入与交付

读取原页面、实际镜头或脚本，以及能够支持核心承诺的证据。
交付原句与改稿对照、证据摆放顺序、十五至三十秒分镜和补拍清单。
给拟拍素材标注状态，引用已提供视频时写时间位置。字幕、配乐和节奏服务主要购买理由。

### 主张、证据与页面原句的映射

沿用虚构回球器，本例材料为一份页面草稿和室内固定点位工程演示。

| 页面原句 | 对应主张 | 现有证据 | 可直接采用的修订 |
| --- | --- | --- | --- |
| “AI 专业教练，持续提高你的命中率” | 持续训练效果 | 仅有工程回球演示，训练对照结果待验证 | “让单人投篮练习少被捡球打断” |
| “任何球场，随处开练” | 广泛环境适配 | 已提供室内固定点位演示 | “面向室内固定点位练习，查看摆位与空间要求” |
| “超强智能芯片” | 技术直接改善体验 | 有技术规格，用户收益对应关系待说明 | 用真实回球演示解释技术在这次使用中完成的任务 |

### 可交付首屏

**标题**

让单人投篮练习少被捡球打断。

**副文案**

在已验证的室内固定点位，原速看一轮投篮、回球和下一次出手。查看摆位要求与工程进度。

**行动按钮**

看完整演示与首批计划

**紧邻的证据**

放置带准备步骤的工程样机演示，标出拍摄条件、产品版本和已验证范围。
429 美元作为本例拟测试售价，页面应同时说明预售或预约状态及交付假设。

### 三十秒拟拍脚本

| 时间 | 画面与操作 | 声音或字幕 | 素材状态与执行 |
| --- | --- | --- | --- |
| 0–4 秒 | 单人出手后走去捡球，保留真实停顿 | “一个人练球，总被捡球打断？” | 视频制作按真实使用补拍 |
| 4–14 秒 | 在已验证位置原速展示一次投篮、回球和接球 | “看一轮真实回球。” | 硬件负责人确认成功条件，标注工程样机 |
| 14–24 秒 | 球员接到球后继续原有练习，短镜头交代摆位 | “按自己的节奏，把这组练完。” | 演示支持多少就呈现多少，时长按实际过程调整 |
| 24–30 秒 | 完整演示入口、使用范围和首批计划入口同屏 | “看看它是否适合你的练习。” | 设计使用已核对的范围文案 |

品牌负责人验收一句主要购买理由是否贯穿画面，硬件负责人核对镜头承诺，视频制作保留原速证据。
原始素材不足时先交分镜和补拍清单，已有素材可用时直接给重排剪辑指令。

## C. 一张付费验证实验卡

### 最小输入与交付

读取最影响决定的未知、目标客群、已有批次、目标售价、预算和可承诺范围。
优先利用现成交易或访谈记录，再设计一个只改变主要假设的实验。
条件从项目经济账与实际阶段推导，明确支持继续验证、调整或停止的范围。

### 完整示例实验卡

本例假设公司要验证将少中断收益前置，能否降低同价净付订成本。
产品、价格、真实演示、交期说明与退款条件在两组保持一致，仅改变首屏表达。

| 项目 | 本轮安排 |
| --- | --- |
| 主要假设 | “少被捡球打断”的表达，比功能名称更能促使目标练球者付订 |
| 对象 | 同一渠道招募的成年单人练球者，排除员工、亲友与重复访问归因 |
| 对照 | A 组首屏为“室内固定点位回球设备”，B 组使用上节收益标题 |
| 分配 | 同一广告引流后随机展示 A 或 B，记录版本、首次访问时间和后续付款 |
| 收费价格 | 两组均明确产品计划价 429 美元，本轮收 5 美元可退订金并全额计入总价，后续余款为 424 美元，明示交付条件 |
| 用户动作 | 看演示和使用范围后完成订金付款，后续保留同批转单与取消记录 |
| 费用及时限 | 建议广告总额上限 600 美元，招募六天，每人按付订后第七天核对取消 |
| 观察口径 | 分组列访问、付订、取消、净付订和分摊广告费，两组沿用同一观察窗口 |
| 成本参照 | 假设可承受有效订单 CAC 为 60 美元，净付订转单率暂按 25% 且后续支出为零，净付订 CAC 上限暂为 15 美元 |
| 继续条件 | B 组净付订 CAC 在参照内且优于 A，才安排同批转全款验证或一轮复测，记录样本量与不确定性 |
| 停止或调整 | 达到费用上限结束新增招募。支付异常或文案与演示不符时先暂停，成本超出参照时检查假设和表达 |
| 负责人 | 增长负责人执行，数据分析核对批次，产品负责人答复使用与交付问题 |

小样本的差异先作为方向信号，报告两组人数及退款窗口，不宣称统计确定性。
25% 转单率属于待验证假设，60 美元须由公司自己的贡献、销量、固定费用和利润要求推导。
后续转化成本或退款增加时重算参照，订金结果支持下一次验证，正式上线另核对经济与交付条件。

## D. 可复算预算与付款调整

### 最小输入与交付

读取净实收、全部成本、服务合同、净订单批次、剩余固定投入和付款日程。
交付费用口径、关键情景、预算边界、已发生成本和回款前的资金缺口。
报价与预测分别标明。固定费抵佣金按合同总收费计算，逐项核对重复扣计。

### 完整示例片段

本例假设下一轮净实收每单 429 美元，全部非广告变动成本每单 309 美元，已含按单服务费，示例各情景沿用此报价。
广告前单笔贡献为 120 美元，尚待投入的固定费用为 4,800 美元，历史试验独立核算。
公司希望本轮至少保留 1,200 美元利润，已有同渠道小样本净订单 CAC 为 50 美元。

| 情景假设 | 净有效订单 | 每单 CAC | 扣剩余固定投入后的结果 |
| --- | --- | --- | --- |
| 下行情景 | 70 | 65 美元 | 70 ×（120 − 65）− 4,800 = −950 美元 |
| 基准情景 | 100 | 50 美元 | 100 ×（120 − 50）− 4,800 = 2,200 美元 |
| 扩量情景 | 150 | 55 美元 | 150 ×（120 − 55）− 4,800 = 4,950 美元 |

100 单下保留目标利润的 CAC 上限为 120 −（4,800 + 1,200）÷ 100 = 60 美元。
净销量预测变化后重算该上限，扩量情景中的成本与销量仍是待核实假设。

假设平台回款前可用现金为 18,000 美元，已安排固定支出 4,800 美元、广告 5,000 美元和工厂预付款 10,000 美元。
该时段支出合计 19,800 美元，已知资金缺口为 1,800 美元。完整现金日程还需覆盖其余付款。
交给财务与供应链的动作是核对工厂分期、最低起订及投放节奏，形成能覆盖缺口的付款安排后再锁预算。
全项目损益另加历史试验收入与成本，下一轮增量测算保留当前边界。

## E. 首批范围与交付承诺修订

### 最小输入与交付

读取承诺原句、工程验证、关键料、试产、认证适用性、工厂排期、质检和现金计划。
交付关键路径、首批数量依据、对外承诺改稿，以及下一次可核实的进度节点。
把建议日期与已确认排期分别标出，延期后的成本和支持者处理方式同步核对。

### 完整示例片段

本例原页面承诺第六周发货。虚构工程计划预计第七周完成关键耐久测试，工厂暂留第九周试产档。
假设试产、整改与出厂检查共需三至五周，供应链提出第十二至十四周发货区间，排期尚待确认。

| 决定性节点 | 角色负责人 | 本轮验收证据 |
| --- | --- | --- |
| 关键耐久测试 | 硬件负责人 | 已完成测试记录、失败项处置和复测结果 |
| 试产及首批范围 | 供应链与质量负责人 | 工厂书面排期、物料确认、试产质量记录及可交数量 |
| 现金与订单处理 | 财务与客服负责人 | 延期现金日程、经确认的订单调整流程与对外入口 |

**供确认后的页面采用的草稿**

我们预计在第十二至十四周开始发送首批产品，时间取决于关键耐久测试与试产验收。
第七周更新耐久测试进展，第十周更新试产和首批数量。若关键节点变化，我们会同时说明影响、调整后的安排及订单处理入口。

现有支持者的进度稿还应写明原承诺受影响的部分、已经完成的工作和支持者现在可采取的行动。
对外日期以工程与供应链确认的最新计划为依据，待确认信息在草稿中保留状态。

## 交付前检查

- 每个主要判断都能指向原材料，推断与假设有清楚标记。
- 提供已写好的文案、分镜、实验安排或可复算数字，让负责人知道接下来做什么。
- 承诺范围与证据匹配，计划售价、预约、预售和成功扣款分别说明。
- 单位经济与现金时间轴一致，剩余投入和全项目损益口径清楚。
- 负责人以角色标明，预算及时限注明已确认或建议，复评条件能够实际观察。
