# 从材料信号形成判断

按当前瓶颈查阅相关条目，把结论落到用户提供的原句、镜头、记录或费用项。
先完成可直接使用的修订，再追问决定性未知。每项修订注明已有证据、推断和待验证条件。
以下产品、材料片段与情境全部虚构，供演示判断方法使用。

## 1. 功能成立后，还要计算使用负担

| 核查角度 | 把材料变成决策 |
| --- | --- |
| 原材料信号 | 页面列出自动识别、云端分析、更多传感器，实际流程仍需用户充电、校准、手工补录或重复确认。 |
| 决策错误 | 用增加的功能推断增加的购买价值，漏掉最容易采用的替代方案和新增负担。 |
| 可执行改法 | 还原一次完整使用，逐步比较现有工具、人工做法与新产品。挑出真正消失的一步、减少的中断或新增的可用结果，把它写进首屏，并安排同场景对照。 |
| 证据边界 | 准确识别只支持识别能力。省时间、减少麻烦和改善结果，各自需要对应观察。使用负担和收益都按目标用户计算。 |

例如，虚构回球器已经完成自动回球，却还需每次十分钟校准。
先核查一次训练减少的捡球时间与准备时间，再决定主推“练得更连贯”还是继续改善开机流程。

## 2. 让具体早期用户愿意等待

| 核查角度 | 把材料变成决策 |
| --- | --- |
| 原材料信号 | 团队称产品面向所有家庭，吸引力主要来自新造型或新技术，价格和等待期限尚未向同一批人说明。 |
| 决策错误 | 将喜欢新奇内容的人、愿意尝鲜的人与愿意付费等待的人混在一起。 |
| 可执行改法 | 收窄到一个已有投入的场景，写清谁现在怎样解决、哪里仍难受、为什么这次值得换。让同一目标群体同时看到产品价值、价格、使用负担和交期，再观察行动。 |
| 证据边界 | 早期支持者的付费证明相应人群与条件下的吸引力。新外观有传播价值，长期使用和大众需求还需后续证据。 |

先区分“第一次看到很想玩”和“每次遇到这个问题都想用”，再选适合本轮众筹的购买理由。

## 3. 用可触达和付费行为建立首日预期

| 核查角度 | 把材料变成决策 |
| --- | --- |
| 原材料信号 | 拿旧活动邮箱、社群总人数、低价可退订金相加预测首日金额，承诺上线后会获得平台推荐。 |
| 决策错误 | 将名单数量当作购买准备程度，忽略重复、失效、价格差异和付款状态。 |
| 可执行改法 | 按来源与时间拆批，核对可触达、净付订、后续付款和取消。用同批记录建立保守首日预期，另列未验证名单与平台流量情景。抽查社群中用户反复问的使用、价格和交付问题。 |
| 证据边界 | 热闹社群可反映关注主题，购买预测需有对应行动。首日承诺、成功扣款和退款后的净订单分别记录，平台流程与当前规则按官方来源核实。 |

将“我们有一万人社群”改成可复算的批次表，并注明谁负责清理名单、哪天复查、什么结果会降低首日预算。

## 4. 让演示和情绪共同推动购买

| 核查角度 | 把材料变成决策 |
| --- | --- |
| 原材料信号 | 前四十秒是创始故事、芯片特写和慢镜头，真实使用只在结尾闪过。运动产品节奏平，用户难以想象自己使用。 |
| 决策错误 | 团队按研发难度安排展示顺序，购买者最关心的体验变化被推迟。 |
| 可执行改法 | 挑一个能看懂的使用中断或愿望开场，尽早给真实使用演示，再用机制解释和用户故事支持。直接改写十五至三十秒分镜，指定真实素材、声音、字幕与拍摄角色。 |
| 证据边界 | 节奏、音乐和情绪可以增强理解与期待。演示中的速度、完成度和结果必须对应实际拍摄，拟拍镜头明确标注。 |

虚构回球器可以从“投一次、走去捡球”的中断，转到原速回球和下一次出手。
视频顺序服务这一个购买理由，关键规格留在能解释体验的镜头旁。

## 5. 把最能减少购买疑虑的证据前置

| 核查角度 | 把材料变成决策 |
| --- | --- |
| 原材料信号 | 首屏只有宏大承诺与优惠，原型演示、适用限制、交付状态藏在长页面底部。 |
| 决策错误 | 让支持者先承担对功能和交付的疑虑，再要求他们耐心寻找证明。 |
| 可执行改法 | 建立主张、现有证据、原文位置的对应表。把最关键购买理由旁边的证明补上，给出可替换首屏、证据顺序及需补拍的一个镜头。 |
| 证据边界 | 工厂照片支持现场存在，功能演示支持演示条件下可用，独立试用支持相应体验。不同主张分别匹配证据范围。 |

优先呈现能够改变购买判断的实物使用与真实结果，并在同处说明当前版本和适用条件。

## 6. 按新增证据评估 KOL 与媒体投入

| 核查角度 | 把材料变成决策 |
| --- | --- |
| 原材料信号 | 多个创作者重复开箱和赞美，页面堆满标识，但仍缺少独立操作、替代品对照或长时使用。 |
| 决策错误 | 用人数和粉丝量替代可信证据的增量，重复内容占用制作和投放预算。 |
| 可执行改法 | 给现有内容标明各自证明了什么、覆盖哪类用户疑虑。新增合作围绕尚未覆盖的关键证明采购，任务书写清实测场景、可公开原始片段和披露要求。 |
| 证据边界 | 创作者使用过产品支持特定体验的可信度。其观众的实际访问、付款和退款需单独归因，曝光量本身无法计算订单贡献。 |

若已有多条开箱，下一笔费用可以优先补同价替代方案对照。是否值得花钱取决于该疑虑对购买的影响和报价。

## 7. 用可信价格保留项目利润

| 核查角度 | 把材料变成决策 |
| --- | --- |
| 原材料信号 | 团队认为早鸟越便宜越好，或凭空抬高未来售价展示大折扣，广告与售后空间随降价缩小。 |
| 决策错误 | 把折扣感、价格接受度、转化率和项目利润当作同一件事。 |
| 可执行改法 | 核对同价真实付款与替代方案，比较目标售价下的净贡献和可承受获客成本。未来计划售价据实标注，价格测试保持客群、承诺和交期可比，并按总贡献选择方案。 |
| 证据边界 | 某批早期用户接受高价，只支持该批条件下的价格证据。等待和交付不确定性也会影响接受度，价格弹性需实际观察。 |

价格较高可能保留执行空间，是否更好还要看实际订单、退款和新增获客成本。

## 8. 在短周期内把素材和代理分工准备到可执行

| 核查角度 | 把材料变成决策 |
| --- | --- |
| 原材料信号 | 上线前只有一条精修主片，团队寄望代理持续投放就能找到受众，表现不佳时再临时拍摄。 |
| 决策错误 | 用执行机构替代产品与购买理由的判断，把短期活动建立在尚未完成的素材试错上。 |
| 可执行改法 | 按不同购买障碍准备少量真正不同的表达，记录每条要验证的假设与结果。团队负责产品承诺、证据和预算边界，代理负责已约定的制作或投放动作、归因及复盘。 |
| 证据边界 | 代理历史案例可以支持执行经验，当前项目还要看实际负责人员、测试记录和投入条件。素材结果随渠道与客群变化，保留原始口径。 |

优先准备一条场景收益、一条真实演示、一条解决最大疑虑的表达。
每条只回答一个主要购买问题，放量条件从本项目经济账和行为数据推导。

## 9. 让交付承诺跟随验证进度

| 核查角度 | 把材料变成决策 |
| --- | --- |
| 原材料信号 | 团队为了赶承诺日期准备发未通过关键测试的硬件，或新增规格却沿用原生产与交付排期。 |
| 决策错误 | 忽略硬件缺陷的退换、售后和口碑代价，遗漏新增规格带来的验证工作与资金消耗。 |
| 可执行改法 | 列出决定首批质量的剩余验证、通过标准、角色负责人和预计完成日。根据关键路径调整批量与承诺，生成具体进度说明及支持者可采取的行动。 |
| 证据边界 | 样机、工程验证、试产和量产有各自可支持的承诺。软件更新覆盖可验证的软件修复范围，硬件问题按实际返工方案评估。 |

延期沟通写清已完成工作、未通过的节点、对用户的影响和下一次可核实的更新。
同时核对继续等待的现金消耗与已承诺的订单处理方式。

## 10. 把众筹后的持续价值接着验证

| 核查角度 | 把材料变成决策 |
| --- | --- |
| 原材料信号 | 众筹金额高就宣布大众 PMF，或广告依赖仍高就直接认定产品失败。 |
| 决策错误 | 忽略尝鲜群体、购买时点、使用习惯和渠道归因的差异。 |
| 可执行改法 | 给首批交付用户设后续观察，核查是否持续完成核心任务、为什么退款或闲置、是否主动推荐。进入新渠道时重新检验价格、口碑、信任与使用门槛。 |
| 证据边界 | 广告依赖是需要追查的经营信号，其解释受品类频次、渠道结构和归因口径影响。对低频硬件，持续使用、闲置原因和推荐往往比复购更贴近价值。 |

把“大家都喜欢”落到具体任务完成、实际使用与推荐记录，再决定下一阶段投入。

## 选择本轮最值得做的一项修订

先处理会使当前上线计划无法兑现的现金、核心功能或交付条件。
其余问题按对购买与利润的影响、现有证据强度、验证成本排序。
在 [交付规格与示例](deliverables.md) 中选对应成果，交给相应角色执行。
