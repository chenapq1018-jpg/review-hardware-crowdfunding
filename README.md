# 我们的产品准备好做众筹了吗？

给每一家准备做众筹的硬件公司的一项免费 Skill。把现有产品资料和上线计划交给 AI，评审购买理由、预热、传播、利润与交付，判断**可按计划上线、先补证再定，还是暂缓当前方案**。

## 用自己的产品评审一遍

可以从一个产品想法、一版众筹页面或已有预热数据开始。提供手边的材料，缺失的信息写“未知”。它会按项目阶段判断，并优先追问最影响决定的问题。

| 自评项目 | 要回答的问题 |
| --- | --- |
| 购买理由与众筹适配 | 谁愿意按这个价格购买，相对现有方案有什么值得等待的改善？ |
| 预热与付费信号 | 名单、社群和订金究竟证明了什么，首日订单预期依据是什么？ |
| 主视频、页面与信任 | 场景、最大特色和用户价值有没有讲清楚，演示和背书能否支持承诺？ |
| 价格、素材与投放 | 价格和折扣是否可信，素材验证了什么，预算何时停止或加码？ |
| 公司利润与现金 | 把广告、服务商、退款和售后都算进去后，项目能赚多少，钱能否周转？ |
| 量产、质量与交付 | 剩余工作、产能、质检与交期能否支持本轮对用户的承诺？ |

输出控制在一屏左右，给出总体建议，并展开最影响决定的 1—3 点，包含依据、优先行动与改判条件。需要时可以要求展示完整六项核查。新数据到来后可以复评，并说明哪条事实改变了判断。

例如，广告花费 600 美元带来 100 人付订，之后 20 人退款，净订金获客成本为 7.50 美元。要判断订单是否赚钱，还需核对这批人的有效全款转化与后续支出。具体缺口、补查动作及取得新证据后的改判，见两轮案例。

## 安装到支持 Skills 的 AI

安装工具需要 Node.js 22.20 或更新版本。在希望使用它的项目目录运行下面一行，再选择自己的 AI 工具。

```bash
npx skills add chenapq1018-jpg/review-hardware-crowdfunding --skill review-hardware-crowdfunding
```

安装后可以这样提问。

```text
请用 $review-hardware-crowdfunding 评审我们公司的产品和众筹计划。
我会提供现有产品资料、页面、视频、预热数据、价格预算和交付计划。
判断能否按期上线，指出最影响决定的证据缺口，并给出优先改进动作。
```

## 免费试用与反馈

本版本免费提供给个人和团队用于项目评审。先记下自己原本准备怎么做，使用后再记录实际补查了什么、调整了什么。反馈表也可以报告算错的账、遗漏的重要事实以及与普通 AI 相比没有改善的地方。

欢迎在第二个产品或取得新数据后再次使用。反馈会随你的 GitHub 用户名公开显示，请填写去掉公司、客户身份和敏感信息的摘要。项目原始数据留在你所选的 AI 使用环境中。
